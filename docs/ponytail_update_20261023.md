# Ponytail 方法检查与更新（2026-10-23）

本项目是本地批处理的降水订正研究流程。本次按照
[Ponytail](https://github.com/DietrichGebert/ponytail) 的
[核心规则](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md)
检查数据读取、累计、时空对齐、指标计算及相关测试，优先修复可复现问题，复用已有模块，不增加依赖。
本次直接应用规则，没有安装全局插件或生命周期钩子。

## 已修复

1. **未知降水单位被误标成毫米。** GFS、ECMWF 原先只识别米，其他单位全部按毫米处理。
   例如 `mm/hr` 会被误当成累计雨量，带空格的米单位也不会换算。
   现在共用 `accumulations.py` 中的单位转换，接受明确的累计雨量单位；缺失、未知或降水率单位明确报错。
   米转换为毫米，液态水每平方米一千克对应一毫米；非有限值继续标为缺测。
2. **ECMWF `.nc4` 文件发现与读取不一致。** 文件发现函数接受此后缀，读取函数却拒绝它。
   现在读取函数支持 `.nc4`，并用真实的临时 NetCDF 文件验证读取与单位转换。

两个读取器原有的重复单位转换函数已删除，调用同一个实现。原有无单位的合成测试数据补充了明确单位。
新增参数化回归测试覆盖两类读取器、合法单位、非法单位、缺测值、源数据保持不变及 `.nc4` 读取。
